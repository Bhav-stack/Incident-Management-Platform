Privacy Policy

Last updated: September 8, 2026

1. What this project is

Aegis is a demo project that simulates application failures and automated incident recovery. It is built to demonstrate systems design and is not a commercial service. This page describes what the project does with data when you run it yourself or view this site.

2. Data collection on this site

This site does not use analytics, tracking scripts, cookies for marketing, or third-party embeds. It does not collect names, email addresses, or any personal information. No accounts are offered and none are required.

3. Data in the demo itself

When you run the project locally, the simulator generates synthetic telemetry (metrics, logs, and health events for made-up services such as checkout-service). All data is fictional, is generated on your own machine, and stays on your own machine. The services persist incident history to your local PostgreSQL instance and ephemeral state to your local Redis instance.

4. Logs

Application logs may be written by the services while they run. These are standard operational logs (startup, errors, processed event counts) and are not transmitted anywhere. The LLM agent, if enabled, sends synthetic incident evidence to the configured model provider. Do not feed real customer data into the demo if that matters to you.

5. Sharing

No data is sold, rented, or shared with third parties, because no user data is collected in the first place.

6. Changes

If this policy changes, the date at the top of this page will be updated. Because this is a demo project, the simplest way to understand the current behavior is to read the source code, which is the authoritative description of what the project does.
